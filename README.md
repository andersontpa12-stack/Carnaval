# 🎉 I.A Escolas de Samba SP

> Consulte informações sobre as escolas de samba de São Paulo de forma simples e rápida.

## 📖 Sobre o projeto
Este projeto permite pesquisar e visualizar informações sobre as escolas de samba do Carnaval de São Paulo. Você pode encontrar uma escola pesquisando pelo nome ou navegando diretamente clicando pelo nome ou pela divisão em que a escola se encontra.

## 🛠️ Tecnologias utilizadas
- ✅ **Python**

## 📂 Como usar
1. Execute o programa
2. **Pesquise** pelo nome da escola de samba desejada **OU**
3. **Clique** sobre o nome da escola ou sobre a divisão que ela pertence
4. As informações serão exibidas na tela! ✨
